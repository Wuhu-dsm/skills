# Evaluation Rubric

Use this rubric when the user asks for scoring or structured feedback. Score each category from 1 to 5.

## 1. Product Thinking

- 1: Implements code without clarifying the user goal.
- 3: Understands the main workflow and covers basic user needs.
- 5: Makes thoughtful product decisions, handles realistic states, and keeps scope appropriate.

Look for requirement clarification, workflow awareness, and sensible prioritization.

## 2. Problem Decomposition

- 1: Starts coding without a plan and gets lost.
- 3: Breaks the task into reasonable steps.
- 5: Creates a clear plan, adjusts as new information appears, and keeps progress visible.

Look for task breakdown, sequencing, and ability to recover from ambiguity.

## 3. Implementation Quality

- 1: Produces fragile or incomplete code.
- 3: Produces working code with acceptable structure.
- 5: Produces clean, maintainable code that fits the surrounding codebase.

Look for correctness, simplicity, naming, local conventions, and appropriate abstractions.

## 4. Testing And Validation

- 1: Does not verify the result.
- 3: Checks the main happy path and a few important cases.
- 5: Validates core behavior, edge cases, and regressions with appropriate tests or manual checks.

Look for evidence that the candidate knows what could break.

## 5. AI Collaboration

- 1: Blindly accepts AI output or avoids using AI effectively.
- 3: Uses AI for acceleration while still reviewing and steering.
- 5: Delegates well, verifies AI output, asks precise questions, and owns final decisions.

Look for prompt quality, critical review, and candidate ownership.

## 6. Communication

- 1: Gives little explanation of decisions or progress.
- 3: Explains the plan, major decisions, and result clearly.
- 5: Communicates like a strong teammate: concise, transparent, and tradeoff-aware.

Look for clarity, calmness under ambiguity, and ability to narrate decisions.

## 7. Interview Readiness

- 1: Would struggle to complete a realistic interview loop.
- 3: Could pass a moderate interview with some rough edges.
- 5: Shows strong hiring signal for the target level.

Base this score on the full session, not only the final code.

## Feedback Format

Use this structure when giving a full evaluation:

```text
Overall signal: Strong / Mixed / Needs practice
Target level calibration: Below / At / Above expected level

Scores:
- Product thinking: X/5
- Problem decomposition: X/5
- Implementation quality: X/5
- Testing and validation: X/5
- AI collaboration: X/5
- Communication: X/5
- Interview readiness: X/5

Highest-signal strengths:
- ...

Highest-signal risks:
- ...

Next practice focus:
- ...
```
